# Bullet writing

- **XYZ:** Accomplished [X], as measured by [Y], by doing [Z].
- **STAR:** Situation, Task, Action, Result, compressed to one line.
- Start with a strong verb, put the result early, keep 1-2 lines.
- Use only numbers in the evidence. If there is no metric, ask the user for one; if none exists, describe scope (team size, volume, frequency) truthfully.
- Mirror the posting's wording for skills the user really has.
- One idea per bullet. No pronouns, no buzzword lists, no "responsible for".
